# letter_high_school ― 3年後の自分からの返信

ワークシート「未来の自分に宛てた手紙」の **03「3年後の自分役のAIから返信を受け取ろう」** で使うウェブサイトです。
高校生がワークシートを2枚の写真に撮ってアップロードすると、AIが読み取り、「3年後の自分」として返信を書きます。

## 画面の流れ

| ページ | 内容 |
| --- | --- |
| 1. 写真をアップロード | 1枚目に「01 プロフィール」、2枚目に「02 手紙」の写真を選ぶ |
| 2. 読み取り結果の確認 | AIが読み取った文章を確認し、違うところを直す（写真を見ながら確認できる） |
| 3. 返信を読む | 「3年後の自分」からの返信が表示される |

- 返信は、確認・修正した **手紙** と **プロフィール** の両方をもとに書かれます。
- 口調は「基本的にカジュアルな表現にして、敬語や堅い表現は極力使わない」にしています。
- 未来に手紙を送る機能はありません。返信を画面に表示して終わりです。

## 保存されるもの

**写真は保存しません。** 写真はAIが文字を読み取るときにだけ使います。
保存するのは文章だけで、1回の利用（写真2枚 → 確認 → 返信）が、データベースの1行になります。
番号（ID）はデータベースが自動で振ります。

| 列名 | 内容 |
| --- | --- |
| `id` | 自動で振られる番号（1, 2, 3, …） |
| `created_at` | 写真を読み取った日時 |
| `ai_age` 〜 `ai_relationships` | プロフィール7項目の **AIの読み取り結果**（直す前） |
| `ai_letter` | 手紙の **AIの読み取り結果**（直す前） |
| `age` 〜 `relationships` | プロフィール7項目の **本人が確認・修正したあと** の内容 |
| `letter` | 手紙の **本人が確認・修正したあと** の内容 |
| `confirmed_at` | 確認・修正を終えて送った日時 |
| `reply` | **AIの返信** |
| `replied_at` | 返信ができた日時 |
| `read_model` / `reply_model` | 読み取り／返信に使ったAIのモデル名 |
| `edit_token` | 本人のブラウザだけが知っている合言葉（他人のデータを書き換えられないようにするためのもの） |

プロフィールの列は、ワークシートの項目と次のように対応しています。

| 列 | 項目 |
| --- | --- |
| `age` | 年齢 |
| `occupation` | 職業・身分 |
| `residence` | 住んでいる場所や環境 |
| `appearance` | 服装・髪型 |
| `personality` | 性格 |
| `activities` | 活動の様子（熱心に取り組んでいること） |
| `relationships` | 人間関係の様子（友達・家族・先輩後輩など） |

途中でやめた場合も、そこまでの内容は残ります（例：読み取りだけして返信を受け取らなかった場合は、`ai_〜` の列だけが入ります）。
テーブル（`letters`）は、最初に使われたときに自動で作られます。

## ファイル構成

```
letter_high_school/
├── public/
│   └── index.html     画面（3ページ）
├── api/
│   ├── read.js        写真2枚をAIで読み取って保存する
│   └── reply.js       確認・修正した内容を保存し、返信を書いて保存する
├── lib/
│   ├── prompts.js     AIへの指示文（返信の口調や長さを変えるときはここ）

├── sql/
│   └── export.sql     保存したデータを日本語の列名で一覧にするSQL
├── package.json
├── package-lock.json
└── vercel.json
```

# 公開までの手順（初めての方向け）

全体の流れは次のとおりです。30分ほどで終わります。

1. GitHub にファイルをアップロードする
2. Vercel で公開する（このとき OpenAI の APIキーを登録する）
3. Vercel でデータベース（Neon）を作って、つなぐ
4. もう一度公開し直す（再デプロイ）
5. スマホで動作を確認する
6. QRコードを作って、ワークシートに貼る

## 0. 用意するもの

- **GitHub のアカウント**（作成済み）
- **Vercel のアカウント**（作成済み。GitHub アカウントでログインできるようにしておくと楽です）
- **OpenAI の APIキー**（`sk-` で始まる文字列）
  - 「1年後の手紙」のサイトで使っているキーを、そのまま使っても構いません。
  - 費用を分けて管理したい場合は、https://platform.openai.com の **API keys** で新しく作ってください。キーは作成時に一度しか表示されないので、メモしておきます。

> APIキーは、パスワードと同じくらい大切なものです。GitHub のファイルの中には書かないでください（この手順では、Vercel の画面にだけ登録します）。

## 1. GitHub にアップロードする

1. ダウンロードした zip ファイルを展開（解凍）します。`letter_high_school` というフォルダができます。
2. https://github.com を開き、右上の **＋** → **New repository** を押します。
3. 次のように入力して、**Create repository** を押します。
   - **Owner**: 自分の個人アカウント（大学などの組織（Organization）は選ばない。Vercel の無料プランでは、組織の Private リポジトリは公開できません）
   - **Repository name**: `letter_high_school`
   - **Private** を選ぶ（生徒に見せる必要はないため）
   - **Add a README file** などは、チェックしない（空のまま作る）
4. 空のリポジトリの画面が出たら、**uploading an existing file** という青い文字のリンクを押します。
5. 展開した `letter_high_school` フォルダを開き、**中身をすべて選んで**（`api`・`lib`・`public`・`sql` フォルダと、`package.json` などのファイル）、ブラウザの画面にドラッグ＆ドロップします。
   - ⚠️ `letter_high_school` フォルダ**そのもの**ではなく、**フォルダの中身**をドロップしてください。
   - `.gitignore` は見えないことがありますが、アップロードされなくても問題ありません。
6. 画面の下の **Commit changes** を押します。
7. リポジトリのトップに、`api`、`lib`、`public`、`sql`、`README.md`、`package.json`、`vercel.json` などが並んでいれば成功です。

## 2. Vercel で公開する

1. Vercel にログインした状態で、https://vercel.com/new を開きます（ダッシュボード右上の **New Project** からも開けます）。
2. GitHub のリポジトリの一覧が出るので、`letter_high_school` の横の **Import** を押します。
   - 初めての場合は、GitHub との連携（Vercel の GitHub アプリのインストール）を求められます。**Only select repositories** を選んで `letter_high_school` を指定するか、**All repositories** を選んで **Install** を押してください。
   - 一覧に出てこない場合は、一覧の下にある **Adjust GitHub App Permissions** から、`letter_high_school` へのアクセスを追加してください。
3. **Configure Project**（設定画面）で、次のようにします。
   - **Project Name**: `letter_high_school`（自動で入っていればそのままでOK）
   - **Framework Preset**: **Other**（自動で選ばれていればそのままでOK）
   - **Root Directory**: `./` のまま
   - **Build and Output Settings**: 何も変えない
4. 同じ画面の **Environment Variables** を開いて、次の1つを追加します。
   - **Key**（または **Name**）: `OPENAI_API_KEY`
   - **Value**: OpenAI の APIキー（`sk-…`）。前後に空白が入らないように貼り付ける
   - **Type** を選ぶ欄があれば **Secret**（保存後は値が見えなくなる、パスワード向けの種類）
   - 入力したら **Add** を押す
5. **Deploy** を押します。1分ほどで「Congratulations」の画面になれば完了です。**Continue to Dashboard** を押します。

> この時点ではまだデータベースがないので、サイトを開いて写真を送ると「データベースが接続されていません」と表示されます。次の手順でつなぎます。

## 3. データベース（Neon）をつなぐ

Vercel の画面の中で、無料のデータベース（Neon / Postgres）を作れます。

1. Vercel のプロジェクト `letter_high_school` の画面で、左のメニュー（サイドバー）の **Storage** を押します。
2. **Create Database**（または **Connect Database**）を押し、一覧から **Neon**（Serverless Postgres）を選んで **Continue** を押します。
   - ボタンが見つからない場合は、左のメニューの **Integrations** → **Browse Marketplace** → **Neon** → **Install** からでも同じことができます。
   - 初めての場合は、利用規約への同意や Neon アカウントの作成を求められます。画面の案内に従ってください（Vercel のアカウントでそのまま作れます）。
3. 設定画面では、次のようにします。
   - **Region（リージョン）**: 迷ったら **Washington, D.C.（iad1 / US East）** を選びます。Vercel のプログラムが動く場所と同じなので、いちばん速く動きます。
   - **Plan**: **Free**
   - **Database name**: 例 `letter-high-school-db`（何でもOK）
4. **Create** を押します。
5. 「プロジェクトに接続する（Connect Project）」画面が出たら、`letter_high_school` を選び、**Development / Preview / Production の3つすべて** にチェックを入れて **Connect** を押します。
   - **Custom Prefix**（接頭辞）の欄は、空のままにしてください。
   - 接続の画面が出なかった場合は、作ったデータベースのページで **Connect Project** を押して接続します。
6. 確認：プロジェクトの **Settings** → **Environment Variables** に、`DATABASE_URL` という名前が増えていれば成功です。

## 4. 再デプロイする（大事）

環境変数（APIキーやデータベースの接続先）は、**次に公開し直したときから** 使われます。データベースをつないだら、必ず公開し直してください。

1. プロジェクトの画面で、左のメニューの **Deployments** を押します。
2. いちばん上の行（最新のデプロイ）の右にある **⋯**（点3つ）を押し、**Redeploy** を押します。
3. 「Redeploy to Production」という確認の画面が出るので、そのまま **Redeploy** を押します。1分ほどで完了し、状態が **Ready** になります。

## 5. スマホで動作を確認する

1. プロジェクトの画面（**Overview**）の **Domains** に表示されている URL を開きます。例：`https://letter-high-school.vercel.app`
   - ⚠️ 生徒に配るのは、この **Domains に表示されている短い URL** です。デプロイごとに作られる長い URL（`…-git-main-….vercel.app` など）は、Vercel にログインしていないと開けないことがあります。
2. 自分で書いたワークシート（試しに書いたもの）を2枚撮影して、最後の返信まで進めてみます。
3. データが保存されたか確かめます（下の「保存されたデータを見る」を参照）。

## 6. QRコードを作る

ワークシートの03に貼る QRコードは、手順5の URL から作ります。

- パソコンの Chrome でサイトを開き、アドレスバーの右側にある共有のアイコン（または、ページの何もないところで右クリック）→ **QRコードを作成** で作れます。
- 作ったQRコードは、生徒のスマホで読み取れるか、印刷前に一度試してください。

# 保存されたデータを見る・Excel で保存する

**ざっと見るとき（Vercel の画面で見る）**：Vercel のプロジェクトの左のメニューの **Storage** → 作ったデータベースを選ぶと、**Database** の欄に表が出ます。**Data** タブで `letters` を選ぶと、保存された内容が見られます。**Query** タブに `sql/export.sql` の中身を貼って実行すれば、日本語の列名で見ることもできます（結果は CSV としてコピーできます）。

**Excel のファイルで保存するとき（Neon の画面を使う）**：

1. Vercel のプロジェクトの **Storage** → 作ったデータベースを選び、**Open in Neon** を押します。Neon の管理画面が開きます。
2. 左のメニューの **Tables** → `letters` を選ぶと、保存された内容が表で見られます。
3. Excel のファイルにするには：
   1. 左のメニューの **SQL Editor** を押します。
   2. このリポジトリの `sql/export.sql` の中身を全部コピーして貼り付け、**Run** を押します。
   3. 日本語の列名（「年齢」「年齢（AI読み取り）」「手紙」「AIの返信」「手紙の修正（修正あり／なし）」など）で、結果が表示されます。
   4. 結果の右下にあるダウンロード（エクスポート）のボタンから、**XLSX**（Excel）または **CSV** を選んで保存します。
      - Excel で開くなら **XLSX** がおすすめです（CSV だと文字化けすることがあります）。

日時は日本時間で表示されます。「状態」の列で、最後（返信）まで進んだかどうかが分かります。

# 内容を変えたいとき

ファイルは GitHub の画面上で直接編集できます。ファイルを開いて右上の鉛筆マーク（**Edit this file**）で編集し、**Commit changes** を押すと、Vercel が自動で公開し直します（1分ほど）。

| 変えたいもの | 編集する場所 |
| --- | --- |
| 返信の口調・長さ・ルール | `lib/prompts.js` の `REPLY_INSTRUCTIONS` |
| 写真の読み取りのルール | `lib/prompts.js` の `PROFILE_READ_PROMPT` / `LETTER_READ_PROMPT` |
| 画面下の問い合わせ先 | `public/index.html` の `CONTACT_TEXT` |
| 画面の文言 | `public/index.html`（日本語で検索すると見つかります） |
| AIのモデル | Vercel の環境変数（下の表）。変えたら再デプロイ |

## 環境変数の一覧

Vercel → プロジェクト → **Settings** → **Environment Variables** で設定します。変えたら再デプロイしてください。

| Name | 必須 | 説明 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 必須 | OpenAI の APIキー |
| `DATABASE_URL` | 必須 | データベースの接続先。Neon をつなぐと**自動で入ります**（手で入力しない） |
| `OPENAI_VISION_MODEL` | 任意 | 写真の読み取りに使うモデル。既定は `gpt-5.6`（「1年後の手紙」と同じ） |
| `OPENAI_TEXT_MODEL` | 任意 | 返信を書くのに使うモデル。既定は `gpt-5.6` |

# うまくいかないとき

| 症状・表示 | 原因と対処 |
| --- | --- |
| Vercel の一覧に `letter_high_school` が出てこない | 一覧の下の **Adjust GitHub App Permissions** から、Vercel にそのリポジトリへのアクセスを許可してください。また、リポジトリが大学などの組織（Organization）のものだと、無料プランでは公開できません。自分の個人アカウントに作り直してください。 |
| サイトを開くと **404: NOT_FOUND** | GitHub に `letter_high_school` フォルダごとアップロードした可能性があります。リポジトリのトップに `public` フォルダがあるか確認してください。フォルダの中に入ってしまっている場合は、Vercel の **Settings** → **Build and Deployment** → **Root Directory** に `letter_high_school` と入れて保存し、再デプロイします。 |
| 「データベースが接続されていません」 | 手順3（Neon をつなぐ）と手順4（再デプロイ）を確認してください。 |
| 「OpenAIのAPIキーが設定されていません」「正しくないようです」 | `OPENAI_API_KEY` の名前と値を確認し、再デプロイしてください。前後に空白が入っていないかも確認します。 |
| 「OpenAIの利用枠（クレジット）が不足しています」 | https://platform.openai.com の **Billing** で、支払い設定や残高を確認してください。 |
| 「指定したAIのモデルが見つかりません」 | `OPENAI_VISION_MODEL` / `OPENAI_TEXT_MODEL` の綴りを確認してください。消すと既定の `gpt-5.6` に戻ります。 |
| 「AIが混み合っています」 | 少し待ってから、もう一度押してください。クラス全員が同時に使うと、OpenAI の利用上限に当たることがあります（自動で2回までやり直します）。続く場合は、数人ずつ時間をずらすと解消します。 |
| 「写真を読み込めませんでした」 | パソコンで iPhone の写真（HEIC形式）を選ぶと読み込めないことがあります。スマホから直接撮影・選択してください。 |
| 読み取りの間違いが多い | 明るい場所で、影が入らないように、書いた部分が画面いっぱいに写るように撮り直してください。2ページ目で直すこともできます。 |
| その他のエラー | Vercel のプロジェクトの **Logs** に、くわしい原因が記録されています。画面の赤い枠の「詳細」にも手がかりが出ます。 |

# 費用の目安

| サービス | 費用 |
| --- | --- |
| Vercel（Hobby プラン） | 無料。上限を超えても自動で課金はされず、止まるだけです。 |
| Neon（Free プラン） | 無料。保存できるのは1プロジェクトあたり約1GBで、文章だけなら数十万件分です。上限を超えても自動で課金はされません。 |
| OpenAI API | 使った分だけ課金されます（写真2枚の読み取り＋返信1回で1人分）。最初に何回か試したあと、https://platform.openai.com の **Usage** で1人あたりの金額を確かめておくと安心です。 |
